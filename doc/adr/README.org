#+title: Architecture Decision Records
#+language: en

One decision per file, numbered in the order they were first written.
To add one, copy [[file:0000-template.org][0000-template.org]] to the next free number;
a revised ADR keeps its number.

Status lives in each file's heading keyword, not here, so this list
cannot go stale. ~grep -H "^\* " doc/adr/0*.org~ lists them with status.
